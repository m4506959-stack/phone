# iPhone 18 Series Official Pre-Order & Keynote Experience
### منصة الحجز المسبق لسلسلة آيفون 18 الرسمية 🇱🇾

منصة ويب متكاملة وعصرية لحجز سلسلة هواتف iPhone 18 الرسمية (iPhone 18 Pro Max, iPhone 18 Pro, iPhone 18 Air, iPhone 18) مع واجهة مستوحاة من مؤتمرات آبل وتجربة ثلاثية الأبعاد تفاعلية.

---

## 🌟 المميزات (Features)

- **🎨 تصميم متجاوب وتفاعلي 100%:** واجهة خلفية المجرة العميقة (Deep Space WebGL) مع إضاءة ديناميكية متوافقة مع حركة الماوس.
- **📱 عرض واقعي ثلاثي الأبعاد لظهر الهاتف:** تصميم دقيق ومطابق لأحدث التسريبات العالمية بدقة عالية وخلفية شفافة وتفاعل ضوئي سلس.
- **🛒 نظام حجز مسبق متكامل:**
  - اختيار الموديل والسعة التخزينية مع تحديث الأسعار الفوري بالدينار الليبي (LYD).
  - نموذج حجز متكامل (الاسم، الهاتف، المدينة، طريقة الاستلام: استلام من الفرع أو توصيل للمنزل).
  - توليد رمز حجز فريد وبطاقة QR Code مخصصة لكل طلب.
  - إرسال بريد إلكتروني تلقائي للعميل بتفاصيل الحجز ورمز التتبع.
- **📦 نظام تتبع الحجوزات (`/track`):** تمكين العملاء من متابعة حالة طلباتهم لحظياً برقم الحجز ورقم الهاتف.
- **🛡️ لوحة تحكم إدارية كاملة (`/admin`):**
  - نظرة عامة ورسوم بيانية وإحصائيات مباشرة.
  - إدارة الحجوزات (تأكيد، إكمال، إلغاء، تحديث الحالة).
  - إدارة المخزون وتحديد الكميات المحجوزة والمتاحة.
  - سجل الأنشطة والعمليات (Audit Logs).
  - إعدادات المتجر وساعات العمل ومعلومات التواصل.
- **🌐 دعم كامل للغتين (Arabic & English):** تبديل سلس بين العربية والإنجليزية مع دعم كامل لاتجاه RTL.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [Next.js 14 (App Router)](https://nextjs.org/)
- **Styling:** Modern Vanilla CSS Modules + Glassmorphism + Keyframe Animations
- **3D & Visuals:** Three.js / WebGL / Dynamic Vector Graphics
- **Database & ORM:** SQLite / [Prisma ORM](https://www.prisma.io/)
- **QR Code:** `qrcode` library
- **Icons & Charts:** `recharts`
- **Authentication:** `bcryptjs` + secure session handling

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الاعتماديات:**
```bash
npm install
```

2. **تهيئة قاعدة البيانات:**
```bash
npx prisma db push
npx tsx prisma/seed.ts
```

3. **تشغيل خادم التطوير:**
```bash
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
